# 棚拍器械与用光对照表

> 用法：在 set.a.light 3D 里每认识一种配件，就填一行：长什么样、光质软硬、典型用途。
> 核心原理一句话：**光质软硬 = 光源面积相对主体越大、距离越近，光越柔；光比 = 主灯与辅灯的亮度差。**

## 一、柔光配件（让光变柔）
| 配件 | 长相/结构 | 光质特点 | 典型用途 |
|---|---|---|---|
| 四角柔光箱 | | 万能基础款，有方向性 | 主光/辅光/侧逆光 |
| 八角柔光箱 | | 光线柔和扩散，眼神光圆形好看 | 半身人像主光 |
| 深抛（抛物线柔光箱） | | 纵深长、指向性强、聚光且过渡柔和 | 主光，需要立体感时 |
| 条形柔光箱 | | 窄长柔光 | 轮廓光/全身侧边补光 |
| 格栅（网格） | | 装在柔光箱前，防止光线外溢 | 控光、压暗环境 |
| 反光伞（银/白） | | 银伞偏硬、方向性强；白伞柔和 | 反射式补光 |
| 透光伞 | | 灯朝伞内打、光穿透伞面，更柔 | 近距离柔和主光 |
| 柔光屏（白旗） | | 大面积散射 | 顶光/削弱硬光 |

## 三、热靴闪光灯用法
| 方式 | 做法 | 效果 | 适用 |
|---|---|---|---|
| 直闪 | 灯头正对主体 | 硬、平、阴影重、油光瑕疵明显 | 记录/远距离补光，少用于人像 |
| 跳闪 | 灯头朝天花板或侧墙，靠漫反射 | 柔和、方向自然 | 室内婚礼/活动/白棚 |
| 离机闪 | 灯从相机取下，用引闪器触发 | 可自由控制光位 | 人像创作、布光基础 |

## 四、经典布光法（在set.a.light里各复刻一遍并截图）
| 布光法 | 灯位 | 特点 |
|---|---|---|
| 单灯主光+反光板 | 主光45°侧前方 | 入门万能 |
| 三点布光 | 主光+辅光+轮廓光 | 经典立体 |
| 派拉蒙（蝴蝶光） | 主光正前方高位，鼻下蝴蝶形阴影 | 时尚、显瘦 |
| 伦勃朗光 | 主光侧45°高位，暗侧脸颊三角光斑 | 油画质感、戏剧 |
| 白棚双灯 | 顶光/轮廓+正面补光 | 干净通透 |
