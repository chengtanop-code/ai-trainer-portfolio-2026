## 1. 任务背景与目标

**业务背景**：摄影师休息时仍会不断收到客户消息，需要AI自动判断每条消息是否值得打断休息。AI判断的依据来自人工标注的数据集——**标注质量直接决定AI判断的可靠性**。

**量化目标**：
- 整体分级准确率 **≥ 85%**
- **L4（紧急）召回率 = 100%**（真紧急消息一条都不许漏，漏判代价最大）
- 标注员之间一致性：Cohen's Kappa ≥ 0.8（高度一致）

## 2. 角色与职责

| 角色 | 职责 |
|---|---|
| 标注员 | 按本SOP打标签；拿不准的消息**一律往高一级判**并标记"待确认"，禁止自行降级 |
| 质检员 | 抽检标注结果（抽检比例≥20%）、统计准确率与Kappa、维护SOP、把典型边界case补进规则 |

## 3. 四级分级定义

### L4 紧急（30分钟内必须响应）
涉及已成交客户的当天/次日档期、资金安全、人身安全或现场事故，错过会造成实际损失或投诉。
判定信号（满足任一）：
1. 已付定金客户的档期确认、改期、退单纠纷
2. 客户已到约定地点但联系不上我方人员
3. 拍摄现场事故、投诉、差评威胁
4. 30分钟内连续催促3次以上（且内容确实紧急）

### L3 重要（当天内必须处理）
有明确成交意向或涉及进行中的业务，当天不回复可能流失客户或影响交付。
判定信号：
1. 客户给出**具体日期/人数**，询问档期（如"明天想拍，建议去哪"）
2. 合同、付款、发票流程中的正常沟通
3. 老客户复购、转介绍
4. 平台派发的限时客资

### L2 可延后（每天固定时间批量回复）
无明确时间压力的咨询、售后或社交寒暄。
判定信号：
1. "在吗""你好"等开场白
2. 泛泛问价、问套餐（无具体日期）
3. 索要客片、底片；售后小问题（如链接打不开）
4. 闲聊、求赞、投票

### L1 垃圾（不回复/直接过滤）
与业务无关的营销、骚扰或无效信息：贷款、理财、刷单、代开发票、同行广告、群@所有人、乱码。

## 4. 标注操作流程

1. 命令行运行 `label-studio start`，浏览器打开 localhost:8080；
2. 进入"客户消息四级分级"项目，点 **Label All Tasks**；
3. 通读消息全文，按第3章定义判断级别；**拿不准 → 选高一级 → 勾选"待确认"标记**；
4. 选定后点 **Submit** 进入下一条；
5. 全部标完后，由质检员按第6章抽检。

## 5. 边界规则（核心，请继续补充）

1. **低置信度升级原则**：L2/L3模糊判L3，L3/L4模糊判L4；
2. **人机协作**：深夜收到无内容的"在吗"，AI先自动回复"在的，您说"，拿到内容后二次分级；
3. **"连催3次"要看内容**：连续多条夸奖/闲聊不算紧急催促；
4. **内部派单单列**：老板/合作方派单不属于客户消息，本版暂记L4，后续单独分类；
5. **待你补充（写3条你能想到的、规则没覆盖的情况）+ 你的处理方式**：
   - 如果是语音我们读不到的 就用AI先回复 您好 暂时读不了语音 麻烦您可以转文字发过来（很多可以用AI做预回复）
   - 摄影师拍的挺好的就是修图我不喜欢 可以再帮我改一下么 这个属于L3 就是客人在等待回复 但这个回复不急 就先不报（或者突然有人甩了几张图过来 然后开始沟通自己想要什么样的照片 这个也属于L3 也是等待回复）
   - 甩过来几张图说如果可以我们就交定金 定了 这个属于L4 因为紧急情况 她可能问了几家 你回的快就是你了

### 易错反例（错误判法，用来提醒新人）
| 消息 | 错误判法 | 正确判法 | 为什么 |
|---|---|---|---|
| 明天想拍，建议拍哪里 | L2 | **L3** | 出现具体日期"明天" |
| 链接打不开，下载好慢 | L3 | **L2** | 售后小问题无时间压力 |
| 连续5条语音夸拍得好 | L4（数条数） | **L2** | 连催要看内容是否紧急 |

## 7. 质检规则

1. 质检员按≥20%比例抽检，计算每条消息判对/判错；
2. 同一批数据由两人独立标注，计算 **Cohen's Kappa**（在线计算器：socscistatistics.com/tests/cohenskappa/）；
3. Kappa < 0.8 → 两人对照SOP讨论分歧、修订边界规则、重新标注该批；
4. 典型错误和边界case定期补入第5、6章，版本号递增。
